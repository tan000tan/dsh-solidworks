# DSH-SolidWorks v0.3.0 系统健康诊断与排障指南

本指南说明如何使用内置的健康诊断系统（Doctor）进行 12 维度环境自检、排查常见故障，以及如何一键生成脱敏诊断报告提交技术支持。

---

## 一、一键运行健康诊断

双击运行插件根目录下的：
👉 **`doctor.bat`**
（或在终端中运行 `node scripts/doctor.js`）

---

## 二、12 大核心检测维度说明

| 维度名称 | 检查内容与合格标准 | 异常级别 |
|---|---|---|
| `OS_PLATFORM_ARCH` | 检查是否为 64 位 Windows (x64/arm64) 且 Node.js >= 18 | `UNSUPPORTED` / `WARN` |
| `PYTHON_RUNTIME` | 检查是否定位到 64 位 Python 3.10+ (优先使用 DSH 自带 Python) | `FAIL` |
| `COM_DEPENDENCIES` | 检查 win32com, pythoncom, comtypes, pydantic, mcp 核心库 | `FAIL` |
| `OPTIONAL_EXTENSIONS` | 检查 DFM/DXF 制造报表扩展（若未安装不影响基础 CAD 建模） | `PASS` (提示扩展) |
| `SOLIDWORKS_REGISTRY` | 检查注册表中是否存在 SldWorks.Application 键值与主程序路径 | `WARN` / `FAIL` |
| `SOLIDWORKS_VERSION_TIER` | 检查当前版本支持级别（2026 物理实测，2020-2025 接口仿真） | `PASS` |
| `STA_DESKTOP_PERM` | 检查交互式桌面会话权限与 STA 单线程套间调度队列 | `FAIL` |
| `LIVE_COM_ECHO` | 检查 SolidWorks 进程心跳、当前活动文档数与版本修订号 | `PASS` |
| `DSH_CLIENT_INTEGRATION` | 检查 DeepSeek Harness 桌面 Profile (`cordis.patch.yml`) 挂载状态 | `WARN` |
| `MCP_CONFIG_VALIDITY` | 检查 `dsh-mcp-config.json` 语法与路径有效性 | `WARN` |
| `MCP_TOOLSET_INTEGRITY` | 检查 73 项完整工具集（2 个宿主策略工具 + 71 个底层 CAD 工具） | `PASS` |
| `SANDBOX_ROOTS_SAFETY` | 检查工作区读写沙箱物理目录权限与路径穿越防御 | `FAIL` |

## 三、常见故障现象与自愈建议

### 1. `PYTHON_RUNTIME` 报错：未找到满足要求的 Python
- **现象**: 提示未检测到 Python 3.10+。
- **自愈方案**:
  - 请确认是否已安装 DeepSeek Harness 客户端；本插件会自动识别 DSH 内置的 Python。
  - 若机器无 DSH，请前往 Python 官网下载安装 Windows 64-bit Python (推荐 3.12 或 3.13)，安装时务必勾选 `Add python.exe to PATH`。
  - 重新双击运行 `install.bat`。

### 2. `SOLIDWORKS_REGISTRY` 警告：未检测到 SolidWorks 注册表
- **现象**: 提示未找到 SldWorks.Application。
- **自愈方案**:
  - 如果您的电脑已安装 SolidWorks，请**以管理员身份手动启动一次 SolidWorks**，进入界面后关闭。这会触发 Windows 自动补全 COM 注册表键值。

### 3. `STA_DESKTOP_PERM` 报错：STA 工作线程异常
- **现象**: 调度超时或拒绝访问。
- **自愈方案**:
  - SolidWorks COM 驱动依赖 Windows 图形交互桌面会话。请勿在无界面的 Windows 服务（Services）、SSH 纯终端后台任务中调用。请确保在当前 Windows 用户登录桌面下运行。

### 4. `DSH_CLIENT_INTEGRATION` 提示未挂载
- **现象**: DSH 配置文件未包含 `dsh-solidworks`。
- **自愈方案**:
  - 双击运行一次 `install.bat`，安装程序会自动完成无损挂载。

## 四、一键生成脱敏诊断报告

每次运行 `doctor.bat` 时，系统会在插件根目录下自动生成两份文件：
1. **`diagnostic-report.json`**: 包含完整机器环境特征的结构化 JSON 报告；
2. **`diagnostic-report.md`**: Markdown 格式的排版摘要，便于直接复制与查阅。

> [!NOTE]
> **隐私脱敏保证**:
> 诊断生成器已自动对用户主机名、本地用户路径中的用户名、私有网络标识进行了星号遮罩脱敏（例如 `C:\Users\***\...`），报告中绝不包含任何密码或私有密钥，可安全发送给技术支持人员协助排障。
