# DSH-SolidWorks v0.3.0 安全卸载与残留清理指南

本指南说明如何在需要卸载或迁移插件时，安全、彻底地清理本插件占用的运行环境与接入配置，同时严格保护用户个人的 CAD 模型资产不受任何损害。

---

## 一、卸载安全红线承诺

本插件卸载工具严格遵守以下安全红线：
1. **绝对不碰用户 CAD 模型**: 任何由用户创建或修改的 `*.SLDPRT`、`*.SLDASM`、`*.SLDDRW`、`*.STEP`、`*.DXF` 文件，卸载程序绝对不予删除；
2. **绝对不影响其他 DSH 插件**: 卸载程序仅从 DeepSeek Harness 配置文件（`cordis.patch.yml`）中移除 `dsh-solidworks` 相关配置段，原有的其他插件与系统设置完好保留；
3. **保留历史配置备份**: 保留 `config-backups/` 目录，确保用户未来重新安装时仍能找到历史配置记录；
4. **不污染全局系统**: 本插件不修改 Windows 系统环境变量与系统注册表全局项，无需清理系统注册表。

---

## 二、卸载操作步骤

### 步骤 1：双击运行卸载向导
在插件目录下，直接双击运行：
👉 **`uninstall.bat`**

### 步骤 2：预览与确认
卸载工具会自动扫描可安全清理的目标（白名单制）：
- 本插件自建的虚拟环境目录 `.venv`；
- 本地生成的配置文件 `dsh-mcp-config.json`；
- 测试沙箱临时中间生成物；
- DSH Profile 中的挂载节点。

按照提示输入 `Y` 或使用命令行参数确认执行：
```bash
node scripts/uninstall.js --yes
```

### 步骤 3：卸载完成确认
终端提示 `🎉 插件临时运行环境已安全清理！` 即代表卸载完成。

---

## 三、残留核验

用户可手动检查以下项目，确认零残留：
- 插件根目录下 `.venv` 目录已删除；
- 插件根目录下 `dsh-mcp-config.json` 已删除；
- 打开 `%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml`，其中已无 `id: dsh-solidworks` 节点；
- 您的 SolidWorks 与 DeepSeek Harness 主程序运行完全不受影响。
