# DSH-SolidWorks v0.3.0 平滑升级与配置回滚指南

本指南说明如何在不丢失现有配置、不损坏用户 CAD 文件的提下，将本插件平滑升级到新版本，或在升级异常时快速执行一键回滚。

---

## 一、升级设计原则

1. **自动快照备份**: 升级脚本在动工前，会自动将当前的所有核心配置及 DSH Profile 文件复制到带有时间戳的独立快照目录 `config-backups/backup-<timestamp>/` 中；
2. **增量依赖补齐**: 仅下载新版本新增或更新的依赖包，已就绪的依赖全部自动跳过，无需重复等待；
3. **闭环验收验证**: 升级完成后自动链式调用健康诊断系统（Doctor），只有自检通过才宣布升级成功；
4. **安全保护承诺**: 升级过程绝不触碰用户的 `*.SLDPRT`、`*.SLDASM`、`*.SLDDRW` 资产文件。

---

## 二、一键升级操作步骤

### 步骤 1：获取新版本文件
将新版本发布包解压并覆盖至现有插件目录（或将新代码拉取至本地）。

### 步骤 2：双击运行升级程序
在插件根目录下，直接双击运行：
👉 **`upgrade.bat`**

（或在终端命令行中执行 `node scripts/upgrade.js`）

### 步骤 3：查看升级输出
升级程序将自动执行以下 4 步流程：
- `[1/4]` 识别当前版本并核验目标版本（如 v0.3.0）；
- `[2/4]` 自动创建配置快照备份至 `config-backups/`；
- `[3/4]` 增量更新 Python 虚拟运行环境与 COM 组件注册；
- `[4/4]` 执行升级后系统健康诊断（Doctor）。

终端显示 `🎉 恭喜！dsh-solidworks-plugin 已成功升级至 v0.3.0！` 即代表升级完成。

---

## 三、配置回滚方案

如果在升级后发现运行异常，或由于本地网络波动导致依赖未完整下载，可使用以下两种方法快速回滚：

### 方法 A：自动回滚指引（推荐）
在 `config-backups/` 目录下找到最近一次升级前生成的快照目录，例如：
`config-backups/backup-2026-11-10T16-29-28-302Z/`

将该目录中的：
1. `package.json`
2. `dsh-plugin.json`
3. `dsh-mcp-config.json`
4. `cordis.patch.yml`（若有）

直接复制并覆盖回插件根目录（以及 DSH Profile 目录 `%USERPROFILE%\.dsh\profiles\desktop\`），即可恢复升级前的配置状态。

### 方法 B：重新执行初始化自愈
双击运行 `install.bat`，安装引导程序具备幂等性与错误自愈能力，会自动检测并修复损坏的环境与配置。
