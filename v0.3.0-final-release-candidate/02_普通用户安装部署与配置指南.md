# DSH-SolidWorks v0.3.0 普通用户安装部署与配置指南

本指南专为没有编程背景、不了解 Python 或命令行配置的普通 SolidWorks 与 DeepSeek Harness (DSH) 用户设计。

---

## 一、安装前准备

在安装前，请确保您的电脑满足以下基本条件：
1. **操作系统**: 64 位 Windows 10 或 Windows 11；
2. **SolidWorks**: 已在电脑上安装合法版本的 SolidWorks 桌面版（支持 2020 至 2026 年份版本），且曾经至少启动过一次（以确保 Windows COM 组件完成系统注册）；
3. **DeepSeek Harness (DSH)**: 电脑上已安装并启动过 DeepSeek Harness 客户端。

> [!NOTE]
> **无需预先安装 Python 或 Node.js！**
> 本插件安装向导会自动探测并复用 DeepSeek Harness 自带的 Python 与 Node 运行环境。即使您的电脑未安装全局 Python，也能全自动完成配置。

---

## 二、一键安装步骤（推荐）

### 步骤 1：下载并解压安装包
获取 `dsh-solidworks-v0.3.0-windows-installer.zip` 并将其解压到您希望放置插件的目录（例如 `D:\dsh-solidworks` 或文档目录）。

### 步骤 2：双击运行安装向导
在解压后的文件夹中，直接双击运行：
👉 **`install.bat`**

### 步骤 3：等待自动安装与自检完成
安装程序将全自动执行以下操作：
1. 检测 Windows 平台架构（x64）；
2. 自动定位可用 Python 环境；
3. 创建独立隔离的运行沙箱；
4. 自动下载并就绪核心 CAD 驱动依赖（已启用国内清华大学高速镜像加速）；
5. 注册 Windows COM 自动化驱动；
6. 自动接入您的 DeepSeek Harness 桌面客户端配置并自动备份原配置；
7. 自动触发系统健康体检。

当终端界面出现：
```
[✔] 安装成功完成！您现在可以在 DeepSeek Harness (DSH) 中直接使用 SolidWorks CAD 插件。
```
即表示安装已全部就绪！

---

## 三、验证安装结果

在解压目录中，直接双击运行：
👉 **`doctor.bat`**

如果看到：
```
[✔ PASS] 12 项检查全部通过，系统健康度: 100% PASS
```
并且在当前目录下自动生成了 `diagnostic-report.md`，则说明当前插件与您的 SolidWorks、DSH 已经实现完美通信。

---

## 四、在 DeepSeek Harness 中使用

启动 DeepSeek Harness 客户端，在对话框中即可直接通过自然语言向 AI 发出 SolidWorks CAD 建模指令，例如：
- *"帮我检查当前打开的 SolidWorks 零件的体积与质量属性。"*
- *"在当前零件的前视基准面上画一个 100x50mm 的矩形并拉伸 20mm。"*
- *"在拉伸体中心切除一个直径 30mm、深度 10mm 的圆孔。"*
- *"为该零件创建工程图并生成标准三视图。"*

> [!TIP]
> **安全防护机制**:
> 默认情况下，插件处于只读安全模式（只允许查看、测量与检查几何）；当需要新建、修改模型时，系统会自动提示确认，保障您的模型资产绝不被意外覆盖。
