# dsh-solidworks v0.2.0 发布候选准备方案与交付材料 (更新版)

## 一、版本号建议与定版依据

- **建议版本号**：`v0.2.0`（次版本号升级，Minor Version Bump）
- **定版依据**：
  1. **重大安全加固**：彻底根治 `lib/policy.js` 中的路径穿越漏洞、相对路径逃逸缺陷，并引入基于祖先遍历的物理真实路径解析算法（`realpathWithAncestorWalk`），抵御符号链接与 Junction 物理逃逸；
  2. **零信任防御基准**：重构未知工具防御机制，未收录工具默认以 `HIGH` 严格防御，并在调用时强制阻断；
  3. **策略契约完善**：固化 66 个底层工具的风险分级表（16 只读、26 标准写入、24 高风险），测试套件断言扩展至 15 项且全量通过；
  4. **代码纯净度保障**：完全清理 Python 临时构建字节码，包内文件结构与 `NOTICE` 声明的 174 个文件严格保持一致；
  5. **环境兼容性纠偏**：物理核实宿主环境为 Windows 11 家庭中文版 64 位 (Build 26200)，夯实物理实测基线。

## 二、面向普通 DSH 用户的中文安装与配置指南（草案）

### 1. 适用环境
- **操作系统**：Windows 10 / 11 64 位（实测支持 Windows 11 家庭中文版 Build 26200）
- **CAD 宿主**：SolidWorks 2024 / 2026（已物理实测支持 2026 SP4.1）
- **Python 环境**：Python 3.10 – 3.13（需安装 `mcp`, `pywin32`）
- **AI 宿主**：DeepSeek Harness (DSH) 桌面版

### 2. 极简安装步骤

#### 第一步：在 DSH 插件市场安装插件
在 DSH 市场中搜索 `dsh-solidworks`，点击安装；或在命令行执行：
```bash
dsh plugin add dsh-solidworks
```

#### 第二步：配置 Python 路径与安全模式（核心步骤）
打开用户配置文件：`C:\Users\<你的用户名>\.dsh\profiles\desktop\cordis.patch.yml`
在文件末尾追加（或修改）如下配置段：
```yaml
  - id: dsh-solidworks
    disabled: false
    config:
      mode: read-only  # 初次使用强烈推荐保持 read-only；需要建模时修改为 standard
      pythonPath: 'C:\Python312\python.exe'  # 修改为你本机的真实 python.exe 绝对路径
      allowedRoots:
        - 'C:\work\projects'  # 允许 AI 读写模型的安全目录
```
> 💡 **提示**：如果不知道 Python 路径，可在终端输入 `where python` 查询；务必使用安装了 `pywin32` 的真实 Python。

#### 第三步：启动 SolidWorks 并验证
1. 打开你的 SolidWorks 软件；
2. 打开（或新建）任意一个零件；
3. 启动 DSH，在对话框中对 AI 说：“检查 SolidWorks 连接状态”。
4. 若 AI 回复状态正常、检出 18 个可用工具，即代表安装圆满成功！
