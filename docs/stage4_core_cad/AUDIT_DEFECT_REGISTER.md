## 一、缺陷分类与严重程度定义

- **CRITICAL（致命）**：导致系统崩溃、COM 死锁、用户生产文件被破坏、安全边界完全被穿透。
- **HIGH（严重）**：核心功能失效、几何计算严重失真、关键建模工作流不可用。
- **MEDIUM（中等）**：局部功能受限、复杂边界情况处理不足、自愈回退策略偏保守。
- **LOW（轻微）**：非关键特征覆盖较窄、体验或配置完善性问题。
- **INFO（建议）**：面向后续阶段的架构演进与优化建议。
