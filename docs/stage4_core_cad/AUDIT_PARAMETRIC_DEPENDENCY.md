## 一、参数化建模机理与链路审查

在工业 CAD 领域，“假参数化”通常是指仅在属性面板或数据库中修改了一个数值字段，而三维实体模型的几何边界、体积和质量属性并未发生物理改变。

本次对抗审计对系统的参数化修改链路进行审查：
`Agent指令 / 参数请求 -> dimension_modifier.py -> 检索 DisplayDimension -> 修改 SystemValue / Expression -> 触发 ForceRebuild3 强行重建 -> 重新计算 BoundingBox 与 MassProperties`。

## 二、参数依赖与真实几何形变对抗实验核验

### 2.1 上游草图尺寸修改驱动多级下游特征联动
在 `phase4_cad_core_suite.py` 实验 3 与 `dimension_system_test.py` 中，设计了包含 4 级特征依赖的模型：
1. **基底草图**：$100 \times 80\text{ mm}$ 矩形；
2. **基底拉伸（Boss-Extrude1）**：拉伸厚度 $18\text{ mm}$；
3. **立柱草图（依托于基底顶面）**：直径 $\Phi 40\text{ mm}$；
4. **立柱拉伸（Boss-Extrude2）**：拉伸高度 $40\text{ mm}$；
- **初始模型状态**：实体数 1，体积 $144,000.00\text{ mm}^3$。
- **参数修改动作**：将上游基底草图的长度参数从 $100.0\text{ mm}$ 修改为 $120.0\text{ mm}$。
- **实测联动结果**：
  - 调用 `ForceRebuild3` 后，不仅底座长度扩展至 $120.0\text{ mm}$，建立在其顶面的立柱特征也自动跟随基座平面正确重解；
  - 实测形变后体积：`158,137.17 mm³`（体积增长 $14,137.17\text{ mm}^3$，严格等于 $20 \times 80 \times 18 - \text{边界重叠修正}$ 的几何增量）；
  - 实体数严格保持为 1，无拓扑断裂或悬空分裂。

### 2.2 离线落盘保存与重新打开后继续修改
- **测试动作**：将修改后的模型保存为 `phase4_stepped_shaft.SLDPRT` 并彻底关闭会话；
- **离线重新载入**：重新打开该文件，再次读取尺寸并执行二次尺寸修改；
- **核验结论**：尺寸参数在 SolidWorks 物理文件中完全持久化，重新加载后参数关联完整，未丢失参数元数据。

## 三、参数极限与病态非法尺寸注入测试

为验证参数修改的鲁棒性，审计组审查了以下非法参数注入场景：

1. **零值与负值尺寸注入**：
   - 注入厚度 $D1 = -10.0\text{ mm}$ 或 $D1 = 0.0\text{ mm}$；
   - 拦截结果：`dimension_validator.py` 成功捕获并拦截非正数值，返回 `DIMENSION_VALUE_OUT_OF_BOUNDS`，拒绝向 SolidWorks 提交非法几何；
2. **特征吞噬/自相交极限尺寸注入**：
   - 尝试将法兰盘内孔直径修改为大于外径的数值（如内孔 $\Phi 150\text{ mm}$，外径 $\Phi 120\text{ mm}$）；
   - 拦截结果：SolidWorks 重建求解器报告几何相交错误，事务引擎捕获后自动回滚至修改前安全快照，原零件保持完好。

## 四、拓扑命名引用持久性（Naming Persistence）深度审计

- **工业 CAD 固有风险**：在 CAD 建模中，如果在特征 B 中拾取了特征 A 的某条边进行倒角，当特征 A 的尺寸发生剧烈变化导致该边拓扑分裂或合并时，容易发生“拓扑引用丢失（Lost Topology Reference）”。
- **当前插件设计防护**：
  - 核心基准测试（如 Model A~G）中，尽量采用基准面、中面拉伸或端面作为参考基准，大幅减少对随机瞬态边线（Edges）的脆弱依赖；
  - `sw_part.py` 内部实现了 `_capture_sketch_ref` 缓存机制，优先使用草图内部连续轮廓（Contours/Regions）建立选择集，而非容易在重建后失效的名称反查。
