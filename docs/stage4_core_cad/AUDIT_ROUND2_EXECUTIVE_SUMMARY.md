## 二、逐项回答第二轮任务书第八节 10 个核心质询

### 1. 第一轮报告中哪些结论得到证实？
- **二维草图绘制与几何约束**：图元坐标计算精确，**全代码库确实杜绝了死坐标 `sgFIXED` 欺诈**；
- **基础拉伸与切除**：实体拉伸凸台、盲孔/贯通切除在基准面与表面的法向控制完全正确，无空气空切；
- **旋转凸台与端面倒角**：实心回转体成型准确，轴端 1.5mm x 45° 倒角真实生成；
- **零信任安全网关**：沙箱越界写入与白名单文件篡改拦截率 100%，One-Shot Grant 单次防重放机制有效；
- **失败物理回滚**：任务失败时 Level 3 逆序物理卸载特征树真实有效，实体数与体积精确清零；
- **文档生命周期管理**：后置活动打开文档数严格归零，无僵尸文档泄漏；
- **工具清单总量**：73 项全量工具列表真实对应（71 FastMCP + 2 Meta）。

### 2. 哪些结论被推翻？
- **“镜像特征实机验证通过”被推翻**：`mirror_feature` 在实机运行时因传参 Mark 违背 API 规范（用了 mark=4 实体标记）且基准面未做多语言适配，调用 100% 抛出异常崩溃；
- **“全局自动自愈闭环达成”被推翻**：代码中根本没有任何自动调整尺寸或自动补充约束的算法，将“删除回滚”包装为“自动修复”属于概念偷换；
- **“运行于 SolidWorks 2024”被推翻**：实测运行环境是 SolidWorks 2026 SP4.1，报告数据来源于脚本第 807 行的静态硬编码；
- **“独立核验器 100% 严谨”被推翻**：Model B/D/G 理论体积直接为 `None`，且对孔位偏移完全不敏感，存在重大检测盲区；
- **“第四阶段达到 ACCEPTED 并可正式关闭”被推翻**：核心需求未完全达标，存在未完成项与功能缺陷，阶段必须更正为 `PARTIALLY ACCEPTED`。

### 3. 哪些项目仍然缺少证据？
- **旋转切除（`revolve_cut`）**：缺乏独立的 E4 级实机模型物证；
- **复杂装配级全局方程式联动**：缺乏跨零件全局变量广播物证；
- **异型孔向导（`HoleWizard`）**：缺乏原生的沉头/螺纹孔特征物证；
- **DSH 复杂多步骤 Agent 自主长链规划**：面对 20 步以上复杂建模，缺乏 Agent 零幻觉、零漂移稳定交付的实测物证。

### 4. 圆周阵列和镜像到底实现到了什么程度？
- **圆周阵列**：底层 `FeatureCircularPattern4` 调用代码完备，隔离实测成功生成 `阵列(圆周)1`（误差 $10^{-7}$）。但主基准套件中因未封装轴对象智能拾取，被草图多圆切除规避；
- **镜像特征**：**底层代码存在严重错误，实机调用报错，处于完全不可用状态（FAIL）**。

### 5. 七个模型的几何是否真正符合设计要求？
- 6 个模型（A, C, D, E, F, G）的内部特征尺寸（孔径、孔位、槽宽深、壁厚）与设计要求严格一致；
- **Model B（阶梯轴）存在缺陷**：键槽从轴心切穿了 19mm（切掉半边轴），不符合机械工程标准盲键槽加工规范。

### 6. 核验器本身是否可靠？
- **不可靠，存在显著假阳性率**；
- 仅核查宏观体积与包围盒，对特征相对坐标错位完全失明；且在 3 个复杂模型上根本未配置理论体积断言。

### 7. DSH 是否真正具备复杂任务端到端能力？
- 仅达到 **Level 3（单任务闭环能力）**，能够完成简单单特征零件的授权与落盘；
- 尚未达到 **Level 4（复杂多特征长流程稳定规划）**。

### 8. SolidWorks 版本和 73 项工具数量是否查明？
- **完全查明**：
  - 真实版本：SolidWorks 2026 SP4.1 (Build 34.4.1.1011)，执行文件位于 `<SOLIDWORKS_INSTALL_DIR>\SOLIDWORKS\SLDWORKS.exe`；
  - 工具数量：71 项 FastMCP 服务端业务工具 + 2 项 Node.js Meta Tools = 73 项全量暴露。

### 9. 自我修复是否真正形成闭环？
- **未形成闭环**；
- 系统具备“质检识别”与“阻断回滚”，但“主动修正错误并重新求解”的代码完全缺失。

### 10. 第四阶段是否可以正式关闭？
- **绝对不允许关闭**；
- 存在镜像特征调用崩溃、自动修复缺失、键槽建模不规范等明确阻碍项，必须暂缓结项。

## 三、四大清单汇总

### 3.1 已完成真实能力清单 (Verified Capabilities)
1. 二维草图几何图元绘制（直线、中心矩形、圆、圆弧、多边形）；
2. 基础几何约束求解（水平、垂直、对称、共线、同心，杜绝死坐标 `sgFIXED`）；
3. 实体拉伸凸台与对称中面拉伸（`FeatureExtrusion3`）；
4. 贯通与盲孔拉伸切除（`FeatureCut4`，法向精准控制）；
5. 旋转凸台轴类成型（`FeatureRevolve2`）；
6. 轴端角度倒角（`InsertFeatureChamfer`）；
7. 独立几何度量（体积、表面积、三维包围盒）；
8. 单零件参数驱动与模型强行重建（`ForceRebuild3`）；
9. 特征树线性遍历与状态探测；
10. Level 3 特征树逆序物理回滚（`rollback_task` 实体与体积清零）；
11. 零信任安全网关拦截（沙箱越界阻断、白名单只读保护、One-Shot Grant 授权流转）；
12. 零文档泄漏看门狗机制（后置文档数严格归零）。

### 3.2 未完成能力清单 (Unfinished Capabilities / Gaps)
1. **特征级镜像（`mirror_feature`）**：修复 Mark 传参（改为 mark=2）及中文基准面别名适配；
2. **特征级圆周阵列工作流接入**：在主建模流程中正式接入 `circular_pattern`，并增加回转轴智能推断；
3. **真实自动修复引擎（Auto-Repair Engine）**：实现针对欠定义草图的约束推荐与安全补齐；
4. **Model B 阶梯轴键槽标准建模**：将键槽改为从圆柱外表面切入的标准 4mm 盲键槽；
5. **DSH Level 4 复杂多步骤任务规划**：提供复合宏工具或整图 FeatureGraph 提交机制；
6. **特征级旋转切除与变半径圆角**：补齐实机独立模型物证。

### 3.3 已发现问题清单 (Defect Register Summary)
- `BUG-01 (CRITICAL)`：`sw_part.py:mirror_feature` 选择集 Mark 传错 (mark=4) 且不支持中文基准面名称，导致实机崩溃；
- `BUG-02 (HIGH)`：全局自我修复（Auto-Repair）代码完全缺失，属于概念偷换；
- `BUG-03 (HIGH)`：`audit_stage4_independent_verifier.py` 在 Model B/D/G 上缺失理论体积校验，存在孔位偏移盲区；
- `BUG-04 (MEDIUM)`：`stage4_benchmark_full_suite.py` 第 807 行硬编码 `"SolidWorks 2024"` 误导全套文档；
- `BUG-05 (MEDIUM)`：Model B 阶梯轴键槽从轴心切穿 19mm，切削手法违背常规机加工艺；
- `BUG-06 (MEDIUM)`：DSH Agent 在 20 步长链原子工具调用中缺乏复合宏工具支撑，易发生参数漂移。

### 3.4 建议修复优先级 (Fix Priority for Round 3)
1. **P0 (阻塞级)**：修复 `sw_part.py` 中的 `mirror_feature`（修正 Mark=2，接入多语言候选集），并在独立测试中验证通过；
2. **P1 (规范级)**：修正 `tests/real_cad/stage4_benchmark_full_suite.py` 中的版本动态获取逻辑，移除 2024 硬编码；
3. **P2 (模型级)**：修正 Model B 阶梯轴的键槽切削逻辑（从表面切入 4mm），重新生成标准模型并更新体积；
4. **P3 (架构级)**：在 Model C 中正式使用 `circular_pattern` 代替草图多圆切除；
5. **P4 (自审级)**：在核验器中引入重心矢量 $[X_c, Y_c, Z_c]$ 比对与微观尺寸校验，补齐理论体积，消除检测盲区。
