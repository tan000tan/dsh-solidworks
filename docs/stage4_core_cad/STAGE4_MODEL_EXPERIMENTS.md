## 一、实验目标与执行准则

Phase 4.6 的目标是通过真实工业机械零件实验矩阵，对第四阶段所建立的 CAD 核心建模能力进行极限全景考核。实验严禁使用死坐标固定约束（`sgFIXED`），必须通过严谨的几何求解、特征构造、拓扑融合与驱动尺寸实现模型创建。

### 1.1 实验评价指标
1. **拓扑纯净性（Body Count）**：所有单一零件的实体数必须严格为 1，杜绝多实体悬空或未融合碎体。
2. **几何度量精度（Geometric Accuracy）**：实测解析体积与理论解析体积的相对误差 $\delta_{vol} \le 0.2\%$。
3. **闭环保存与重开（Save & Reopen Consistency）**：零件落盘保存、彻底关闭当前文档后离线重新打开，复核质量属性与特征树一致性（$\Delta V < 0.01\text{ mm}^3$）。
4. **生命周期恢复（Baseline Restored）**：全部实验执行完毕后，SolidWorks 活动文档数必须严格归零。

## 四、结论与技术发现

1. **切除方向物理规律**：
   - 在基准面（Plane）上建立草图向实体内部切除时，切除方向需要设为 `direction=True`；
   - 在实体外表面（FACE）上建立草图时，草图法向朝外，默认切除方向即为深入实体内部，必须设置 `direction=False`，否则会切向空气导致假阳性。
2. **多特征交叉切除几何规律**：
   - 表面多槽相交结构若分多次切除，由于第一次切除后原坐标处实体表面已内凹至槽底，后续草图选择必须避开已被挖空区域，或采用 12 边形单草图精密轮廓切除，确保几何拓扑完全确定。
3. **实体融合规律**：
   - 中面拉伸筋板若直接相切于曲面外侧，容易因切点外悬空产生多实体。将草图边界伸入壁厚内部后进行拉伸，再通过后续孔特征修边，可 100% 保证实体融合为严格单实体（`body_count == 1`）。
