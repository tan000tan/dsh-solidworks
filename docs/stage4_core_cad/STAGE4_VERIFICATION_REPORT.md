## 一、核验目标与评价架构

本报告记录第四阶段 CAD 核心建模能力的系统级独立质量验证与负面故障注入测试。验证严格贯彻零信任原则，不依赖被测接口的自我上报状态，全部通过独立几何度量、外部进程探针、模型质量检测器（MQI）与统一审查协议（URP）进行多维交叉校验。

### 1.1 核验多维评价矩阵
1. **几何与拓扑真确性**：实体数严格单一（`body_count == 1`），欧拉-庞加莱示性数（Euler-Poincaré Formula）闭合性检测；
2. **参数化驱动与特征树健康度**：驱动尺寸修改后几何正确联动，特征树中无父子循环依赖、无抑制失败、无未求解警告；
3. **负面故障注入与边界防御**：越界尺寸注入、自相交轮廓切除、沙箱外非法路径写入、白名单受保护文件篡改；
4. **Level 3 物理回滚闭环**：发生严重几何破坏或建模故障时，特征树必须严格逆序卸载，模型状态干净复原。

## 二、URP 六维核验实测数据

依据《全局自我审查、自我诊断、自我修复系统规范 V2.0》（`GLOBAL_SELF_REVIEW_ENGINE_SPECIFICATION_V2.md`），对 Phase 4.6 产出的核心模型进行 URP 独立审查：

### 2.1 拓扑示性数与封闭流形验证
根据闭合三维实体流形的广义欧拉示性数公式：
$$V - E + F = 2(S - G) + H$$
- **Model A（带孔底板）**：
  - 外表面为单连通封闭体，中心贯通孔引入 1 个贯穿通孔（环柄 $G = 1$），无内空腔（$H = 0$），实体数 $S = 1$。
  - 理论欧拉数：$V - E + F = 2(1 - 1) = 0$。
  - 实测拓扑结构严格满足亏格 1 的环面流形几何特征，无非流形边（Non-manifold edges）。
- **Model E（十字滑块）**：
  - 顶面开设贯通相交槽，实体外表面拓扑亏格 $G = 0$，无内部孤立空腔。
  - 实测拓扑结构严格满足球面同胚流形（$V - E + F = 2$）。

## 三、负面故障注入与容错防御实验

为验证建模引擎在面对异常指令和非法操作时的鲁棒性，执行了以下对抗性故障注入测试：

### 3.1 故障场景 1：沙箱越界路径写入拦截 (Path Traversal)
- **注入动作**：请求将生成的零件保存至沙箱外部敏感目录：`C:\Windows\System32\payload.SLDPRT`。
- **系统反应**：
  - Policy Gateway 拦截命中；
  - 错误码：`PATH_OUTSIDE_ALLOWED_ROOTS`；
  - 阻断层级：DSH 插件网关层物理切断，未经由 SolidWorks COM 执行；
  - 结果：**PASS（非法写入 100% 阻断）**。

### 3.2 故障场景 2：只读受保护模型篡改拦截 (Protected File Tampering)
- **注入动作**：请求对用户白名单受保护零件 `tests/real_cad/fixtures/垫圈.SLDPRT` 执行尺寸修改与破坏性覆盖保存。
- **系统反应**：
  - Policy Gateway 识别目标文件处于全局受保护白名单；
  - 错误码：`PROTECTED_FILE_REFUSED`；
  - 拒绝修改任何草图与特征；
  - 结果：**PASS（白名单文件完整性 100% 保全）**。

### 3.3 故障场景 3：参数化非法几何尺寸注入 (Degenerate Geometry Injection)
- **注入动作**：将外径 $60\text{ mm}$ 的法兰盘中心孔径修改为 $120\text{ mm}$（孔径等于或大于外轮廓，导致实体几何消失）。
- **系统反应**：
  - 几何预检器抛出 `GEOMETRY_SELF_INTERSECTION_DETECTED`；
  - 事务引擎捕获异常，拒绝将非法尺寸提交至模型主特征树；
  - 模型尺寸自动保持原有设定值（$\Phi 30\text{ mm}$），模型未破坏；
  - 结果：**PASS（病态几何破坏被成功阻断）**。
