## 一、实施节奏与迭代原则

第五阶段采用**“模块化独立研发 -> 严格单元测试验收 -> 逐步集成贯通”**的稳健推进策略，坚决杜绝把所有模块混在一起粗放式开发的低级错误。

阶段划分严格对应六个子里程碑：
1. **M1 (S5-A)：** 需求解析与多方案规划引擎落地
2. **M2 (S5-B)：** 复杂特征树规划与拓扑优化器落地
3. **M3 (S5-C)：** 自动迭代修改与影响分析引擎落地
4. **M4 (S5-D)：** 装配智能规划与约束分析器落地
5. **M5 (S5-E)：** 多维综合质量评价与优化引擎落地
6. **M6 (S5-F)：** 协调器统一串联、端到端自主建模实机验证与收敛

---

## 二、子阶段详细任务分解与产出里程碑

### 里程碑 M1：S5-A 需求解析与多方案自动规划
- **核心任务：**
  1. 编写 `multi_scheme_planner.py` 核心实现；
  2. 实现车削策略、拉伸堆叠策略、减材切削策略三大多方案生成算法；
  3. 实现基于特征数、参数自由度、重建风险的量化加权打分模型；
  4. 编写配套独立单元测试 `tests/stage5_multi_scheme_planner_test.py`。
- **准出验收标准：**
  单元测试 100% 通过，能够针对典型需求生成至少 2 个差异度 $\ge 30\%$ 的结构化方案并给出科学选优。

### 里程碑 M2：S5-B 复杂特征树规划与依赖优化
- **核心任务：**
  1. 编写 `complex_feature_tree_optimizer.py` 核心实现；
  2. 实现终饰特征（圆角/倒角）智能后置重排算法；
  3. 实现禁用特征（`mirror_feature`）自动拦截与草图对称替代重构；
  4. 编写配套独立单元测试 `tests/stage5_feature_tree_optimizer_test.py`。
- **准出验收标准：**
  能够优化 10 级特征树拓扑，消除潜在引用断裂风险，死锁检测准确率 100%。

### 里程碑 M3：S5-C 自动迭代修改与影响分析
- **核心任务：**
  1. 编写 `auto_iteration_engine.py` 核心实现；
  2. 实现基于 DAG 的修改影响域分析与级联波及半径计算；
  3. 实现增量安全修改与几何 Diff 比对算法；
  4. 编写配套独立单元测试 `tests/stage5_auto_iteration_test.py`。
- **准出验收标准：**
  在不破坏历史特征树前提下完成增量参数修改与前后的体积/表面积 Diff 计算。

### 里程碑 M4：S5-D 装配智能规划与约束分析
- **核心任务：**
  1. 编写 `assembly_planner.py` 核心实现；
  2. 构建包含组件节点与配合边的 `AssemblyPlan` 数据模型；
  3. 实现基准件自动固定、装配时序拓扑排序与配合冲突预检；
  4. 编写配套独立单元测试 `tests/stage5_assembly_planner_test.py`。
- **准出验收标准：**
  输出完整的装配拓扑关系树，配合冲突检测覆盖率 100%。

### 里程碑 M5：S5-E 多维综合质量评价与优化
- **核心任务：**
  1. 编写 `cad_quality_inspector.py` 核心实现；
  2. 建立几何、拓扑、重建稳定性、工艺性四维雷达评分算法；
  3. 增加关键空间坐标微观采样算法，彻底根除孔位偏移钝化漏洞；
  4. 编写配套独立单元测试 `tests/stage5_quality_inspector_test.py`。
- **准出验收标准：**
  对孔位错位、过薄壁厚、尖角未倒角等问题给出低于 80 分的扣分并输出明确优化建议。

### 里程碑 M6：S5-F 协调调度器与统一端到端验证
- **核心任务：**
  1. 编写 `advanced_ai_cad_coordinator.py` 整合全量五大模块；
  2. 编写全流程集成测试 `tests/stage5_advanced_aicad_integration_test.py`；
  3. 运行实机真实 SolidWorks 进程验证（Model A 多方案自主规划并建模执行）；
  4. 保证 `npm test` 68/68 项全绿且脱敏完全合规。
- **准出验收标准：**
  全套第五阶段测试通过，SolidWorks 活动文档归零，形成可复核的运行物证。
