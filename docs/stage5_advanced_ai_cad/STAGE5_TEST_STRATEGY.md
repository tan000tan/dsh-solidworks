## 一、量化测试目标与评价准则

为杜绝“自测自评”和“测试场景单一”的弊病，第五阶段建立严格的量化测试矩阵与公差标准：

1. **测试用例分类全覆盖：** 每个模块必须覆盖正常输入、边界极限输入、错误非法输入、参数扰动与逆向故障注入；
2. **拒绝盲区核验：** 几何比对必须包含微观坐标采样，不得仅依靠宏观体积；
3. **真实公差标准：**
   - 机械零件体积相对误差容差：$\epsilon_V \le 0.01\%$；
   - 表面积相对误差容差：$\epsilon_S \le 0.05\%$；
   - 局部关键坐标采样绝对误差容差：$\Delta x, \Delta y, \Delta z \le 0.001\text{ mm}$；
   - 重建耗时容限：典型零件（$\le 10$ 级特征）强制重建时间 $\le 3.0\text{ s}$。

## 三、对抗性与负向注入测试设计

1. **违禁特征调用注入测试 (S5-B/S5-F)：**
   - 模拟上层 Agent 试图在特征图中添加 `solidworks_mirror_feature`；
   - **预期表现：** 优化器守卫直接拦截并输出重构提示，阻止其向物理层下发；
2. **孔位偏移钝化攻破测试 (S5-E)：**
   - 人为将螺栓通孔坐标沿 X 轴偏移 $10\text{ mm}$，此时体积完全不变；
   - **预期表现：** 综合质量评价引擎的局部坐标微观采样检测到偏差超出 $0.001\text{ mm}$，几何分项直接扣除 40 分，总分判定低于 80 分不合格，并输出具体的孔位错位警告；
3. **配合冲突过约束注入测试 (S5-D)：**
   - 尝试对同一个回转柱体同时添加两个同轴配合但轴线存在夹角；
   - **预期表现：** 装配规划器在构建约束图时识别出同心约束冲突，阻断装配并报告配合冲突细节。

## 四、测试环境与执行保障

1. 测试在本地 Python 3.13 环境下执行，带参数 `-B` 杜绝生成 `.pyc` 字节码；
2. 测试前通过 `sw_connect` 探测 SolidWorks 2026 SP4.1 处于干净就绪态；
3. 测试后必须强制关闭新建的测试文档，确保活动文档数严格归零；
4. 运行 `npm test` 验证宿主安全策略、MCP 协议、数据包契约保持 100% 绿灯。
