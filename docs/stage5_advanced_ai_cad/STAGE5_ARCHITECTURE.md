## 一、架构设计原则

1. **分层解耦与高内聚：** 规划层（意图解析/方案比选/装配规划）与底层物理驱动层（SolidWorks COM）严格隔离，规划引擎纯算法化，便于离线快速迭代与自动化单元测试；
2. **证据隔离防污染：** 严格遵循《跨阶段能力依赖验证矩阵》，对前四阶段遗留的缺陷接口（如镜像特征崩溃、假自愈）设置物理防线；
3. **确定性与可复现性：** 任何多方案评分、拓扑优化与影响域推导，必须采用确定性数学模型，杜绝随机性或不可预测行为；
4. **面向工业工程实践：** 方案规划与质量评价深度贴合机加工、铸造、钣金等实际制造工艺准则。

## 三、各核心子系统架构职责

### 3.1 多方案规划与比较引擎 (Multi-Scheme Planner) [S5-A]
- **输入：** 零件需求规格（类型、主轮廓尺寸、功能孔、过渡要求）；
- **策略库：**
  - *回转车削策略 (Turning Scheme)：* 适合轴对称旋转体，以轴心草图回转成型为主，特征树极度紧凑；
  - *阶梯堆叠拉伸策略 (Additive Extrusion Scheme)：* 适合多阶台阶，由主基座自底向上逐层拉伸成型；
  - *实体减除切削策略 (Subtractive Scheme)：* 适合箱体与支架，先建毛坯实体，再以多阶盲孔/通孔切削内部；
- **评估器 (Scheme Evaluator)：** 对每个候选方案构建抽象 IR，从特征数量、参数自由度、失败风险三个维度输出加权评分并推荐最优解。

### 3.2 复杂特征树优化器 (Complex Feature Tree Optimizer) [S5-B]
- **图转换引擎：** 将多方案选定的逻辑特征树编译为规范的 `FeatureGraphIR`；
- **拓扑重构与冗余消除：**
  - 检测重复草图与可合并切除操作；
  - 自动调整无依赖特征的时序，将倒角圆角等终饰特征后置，提高模型重建鲁棒性；
  - 强制规避禁用特征（如将镜像需求解构为对称草图约束）。

### 3.3 自动迭代与影响域分析引擎 (Auto Iteration Engine) [S5-C]
- **特征树感知：** 读取当前零件已有特征清单与尺寸标注；
- **影响域推导 (Impact Radius Analyzer)：** 基于特征依赖 DAG 静态分析修改参数将波及的直接下游（Direct Children）和间接下游（Indirect Descendants）；
- **增量修改计划器 (Incremental Plan)：** 规划修改顺序，调用安全尺寸修改工具；
- **几何 Diff 校验：** 比对修改前后的几何属性差值，确认仅目标区域发生变更，非关联区域保持零扰动。

### 3.4 装配智能规划器 (Assembly Planner) [S5-D]
- **装配拓扑图 (Assembly Graph)：** 包含零件节点（`ComponentNode`）与配合边（`MateEdge`）；
- **基准定位器：** 确定主基准零件并自动施加固定约束（`is_fixed=True`）；
- **配合约束规划与冲突求解：** 拓扑排序装配顺序，并在添加配合前检测自由度冲突与同轴/平行过约束。

### 3.5 多维质量评价引擎 (CAD Quality Inspector) [S5-E]
- **多维雷达图评分体系：**
  - $S_{\text{geom}}$（几何公差与局部采样得分，权重 30%）；
  - $S_{\text{topo}}$（拓扑规范与草图完全定义得分，权重 25%）；
  - $S_{\text{rebuild}}$（重建稳定性与回转无报错得分，权重 25%）；
  - $S_{\text{mfg}}$（机械加工工艺性得分，权重 20%）；
- **综合判定：** 输出综合质量总分 $Q = \sum w_i S_i$，低于 80 分输出显式优化建议。
