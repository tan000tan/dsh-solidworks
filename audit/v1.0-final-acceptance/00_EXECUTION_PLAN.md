## 二、不可逾越的最高安全红线

1. 坚决不关闭用户当前正在使用的 SolidWorks 实例；
2. 坚决不关闭任何未由本测试任务明确登记创建的文档；
3. 源码与测试全生命周期坚决禁止调用 `CloseAllDocuments`；
4. 任何操作坚决禁止静默丢弃用户未保存修改；
5. 坚决禁止将 `ActiveDoc` 默认作为自动化写操作目标；
6. 坚决不修改系统注册表、PATH 变量或破坏现有环境配置；
7. 坚决不执行任何未授权的 GitHub push 或市场公开发布。
