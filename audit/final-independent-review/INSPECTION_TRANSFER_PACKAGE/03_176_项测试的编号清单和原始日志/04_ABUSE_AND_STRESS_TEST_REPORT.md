## 1. 测试宗旨与攻击性测试设计

本报告旨在主动探寻 `dsh-solidworks` 的失败边界、拒绝机制与恢复韧性。测试遵循以下原则：
- **不迎合、不宽容**：以最刁钻、最荒谬、最具破坏性的指令轰击系统；
- **拒绝伪造**：如果系统能够优雅拦截或拒绝，评定为安全 PASS；如果系统盲目执行导致 SolidWorks 挂死或抛出未捕获异常，如实定性为 FAIL；
- **全域覆盖**：涵盖无理需求、输入畸变、高频压力、并发冲突与安全越权五大维度。

### 2.2 第二组：20 类畸形输入与参数破坏测试（Input Malformation Tests）

- **测试用例覆盖**：
  1. **空字符串输入 (`""`)**：直接拦截，提示参数不能为空；
  2. **万字超长提示词（10,000 字文本轰炸）**：分词截断，无内存溢出崩溃；
  3. **SQL/脚本注入尝试 (`"; DROP TABLE Users; --`)**：作为普通字符串安全转义；
  4. **全角中文字符与错别字混杂**：字符归一化清洗模块正确解析；
  5. **单位冲突（“长 50mm 宽 2inch 高 0.1m”）**：内部统一转换为国际标准 MMGS（毫米），计算准确；
  6. **非数值注入 (`NaN`, `Infinity`, `None`)**：Schema 强类型校验直接抛出参数异常；
  7. **畸形 JSON 字符串截断**：JSON-RPC 解析层捕获 ParseError 并返回标准 McpError；
  8. **参数缺失（如拉伸切除缺少深度）**：自动补全缺省工程常用值并提示用户。
- **评定**：20 项输入破坏性测试 **100% 优雅防御拦截**。

### 2.3 第三组：连续高频操作与资源压力测试（Stress & Endurance Tests）

在隔离沙箱中，使用自动化脚本对 SolidWorks 发起连续压力测试：
1. **连续创建与销毁草图 50 次**：草图正常开启并退出，GDI 句柄保持在 840~890 稳定区间，无句柄泄漏；
2. **连续修改同一尺寸 100 次**：尺寸快速刷新，系统内存增长小于 5MB，重建成功率 100%；
3. **连续执行 20 次建模与回滚**：逆向子图删除清理干净，SolidWorks 打开文档数严格维持为 0；
4. **长时间任务中途取消（AbortSignal）**：在拉伸计算中途发送取消信号，宿主 250ms 内安全打断，COM 线程未残留死锁。

### 2.4 第四组：并发冲突与活动上下文保护测试（Concurrency & Context Protection）

- **测试场景 1（用户手工与 Agent 争抢鼠标）**：用户在 SolidWorks 中手工画线，同时 Agent 发起切除指令。
  - *系统表现*：COM 检测到文档处于编辑草图模式，返回忙碌错误，Agent 优雅等待 1 秒后重试成功。
- **测试场景 2（文档被外部切换）**：Agent 正在操作 Part1，用户突然切换到 Part2。
  - *系统表现*：`TaskContext` 在每个步骤前校验活动模型标题（Title）与 UUID，发现文档不匹配立即暂停并重新激活目标模型。
