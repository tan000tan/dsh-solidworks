- **自动搜索种子解释器：** 探测系统环境变量、DSH Primary Runtime、已挂载磁盘根目录中的 Python 3.10+。

- **DSH 宿主自动挂载：** 自动向 `%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml` 注入插件配置。

## 三、安全卸载与残留保护测试 (Safe Uninstallation)

### 3.1 卸载安全规范
- **白名单保护原则：** 卸载脚本仅清理插件私有临时文件（`.venv/`, `__pycache__/`, 临时测试日志），**绝对禁止删除任何属于用户的 CAD 资产文件**。
- **模拟演练（Dry-Run）机制：** 支持 `--dry-run` 参数，仅输出将要清理的路径清单，供审计与用户确认。
- **DSH 配置解绑：** 从 `cordis.patch.yml` 中安全注销 `dsh-solidworks` 插件，不影响 DSH 其他插件运行。

### 3.2 实机测试记录
- **执行命令：** `node scripts/uninstall.js --dry-run`
- **实测结果：**
  - 正确识别出待清理的虚拟环境目录与构建缓存。
  - 明确标出用户 CAD 模型白名单受保护规则，未标记任何用户资产。
  - 模拟注销 DSH 宿主插件配置。
- **退出码：** `0` (PASS)
