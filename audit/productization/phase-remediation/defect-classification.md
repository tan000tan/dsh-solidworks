# 缺陷分类与整改优先级表 (defect-classification.md)

**任务基准：** `tan000tan/dsh-solidworks` v0.3.0  
**整改原则：** 聚焦真实产品能力，安全第一，免配置彻底隔离，消除过度承诺

---

## 一、缺陷分类分级总表

| 缺陷 ID | 严重级别 | 缺陷分类 | 缺陷名称与现象 | 影响范围 | 拟采取整改方案 |
|---|---|---|---|---|---|
| **BUG-001** | **P0** | **安全授权** | **高危操作 AI 自授权漏洞**：AI 可自行调用 `solidworks_confirm` 获取 grant，绕过人类审批实质。 | 全局高危工具 (`solidworks_save_document` 等) | 升级确认机制，要求确认必须携带人类明确确认的标记或来源验证，对未经验证的自动调用执行 Fail-Closed。 |
| **BUG-002** | **P1** | **免配置与隔离** | **宿主 Python 环境被污染风险**：`discover.js` 的 `tryAutoBootstrap` 直接在候选解释器中 `pip install`。 | 宿主全局 Python、DSH 主运行时 | 重构为**插件专属 `.venv` 隔离自举机制**：探测到种子 Python 后，自动在插件内部创建 `.venv`，只在 `.venv` 内装包，零污染外部宿主。 |
| **BUG-003** | **P1** | **免配置与可用性** | **普通用户无 Python 时无法自闭环启动**：若宿主机未预装 Python 且无 DSH 主运行时，直接报 `PYTHON_NOT_FOUND` 阻塞。 | 全新 Windows 普通用户客户机 | 提供自动引导与一键式便携式运行时接入方案，在诊断中给出明确修复指引与全自动自愈路径。 |
| **BUG-004** | **P1** | **测试覆盖完整性** | **71 项 CAD 工具尚未建立逐项端到端追踪矩阵**：此前仅对核心 11 步 CAD 闭环测试，未对全部 71 项工具建立参数与返回契约矩阵。 | 71 个底层 CAD 核心工具 | 遍历 71 项工具建立完整参数边界、返回值、授权等级、测试方法与追踪矩阵（`traceability-matrix.md`）。 |
| **BUG-005** | **P2** | **生命周期与容灾** | **COM 断开与进程异常恢复机制未完善验证**：CAD 崩溃或异常退出时，服务重连与幂等清理需要严密测试。 | MCP 长期运行稳定性 | 在 MCP 客户端增加重试限制与死锁超时保护，强化 `DesktopPinnedStaWorker` 的异常退出清理。 |
| **BUG-006** | **P2** | **历史资产管理** | **`dist` 目录清理引发的历史包归档误解**：原 dist 中的 0.1.0/0.2.0 在清理后缺少可见的规范目录。 | 交付与归档规范 | 从根目录备份完整复原 `dist/` 归档结构，并记录哈希，消除历史包丢失担忧。 |
| **BUG-007** | **P3** | **文档与体验** | **多版本与免配置边界在文档中存在轻度过度承诺**：未在显要位置区分 2026 实机与 2020-2025 接口模拟。 | 交付主文档与用户指南 | 在所有 6 份主文档及插件描述中统一口径：明确实机 2026，其余版本为接口降级兼容；明确免配置的技术边界。 |

---

## 二、整改实施批次规划

1. **第一批次 (核心代码与安全隔离整改 - BUG-001, BUG-002, BUG-006)**：
   - 重构 `lib/discover.js`，实现插件专属 `.venv` 零污染安全自举；
   - 强化 `lib/policy.js` 与 `lib/index.js`，堵塞 AI 自授权漏洞；
   - 规范复原 `dist/` 归档目录结构。
2. **第二批次 (工具矩阵与功能全覆盖 - BUG-004, BUG-005)**：
   - 建立 71 个 CAD 工具全量追踪矩阵；
   - 针对异常断开、超时、重连与并发进行专项加固。
3. **第三批次 (全面暴力测试与多维度验证 - 阶段 F/G/H)**：
   - 运行全新隔离环境安装测试、安全对抗测试、CAD 实机物理闭环、异常注入测试。
4. **第四批次 (交付物包装与文档一致性订正 - 阶段 I/J)**：
   - 重新生成交付压缩包、SHA256 清单及完整交付文档。
