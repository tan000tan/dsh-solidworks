## 一、物理物证体系与证据分级定义

为保证所有审计结论具有不可推翻的工程事实支撑，本项目建立五级实物物证索引库：
- **[E0] 文档证据：** 任务书、架构规范、预研分析报告；
- **[E1] 代码物证：** 生产代码源码、接口定义、参数 Schema；
- **[E2] 离线测试物证：** Node.js 与 Python 单元测试、JSON-RPC 通信测试、打包与脱敏测试；
- **[E3] 实机测试物证：** 连接本地真实 SolidWorks 进程、调用 COM 接口生成特征树的运行日志；
- **[E4] 独立复核物证：** 独立提取双精度几何属性、持久化 `.SLDPRT` 磁盘文件、关闭并在全新会话中重开验证。
