## 四、任务二：DEF-03 运行时版本号统一

### 4.1 方案与修复内容
- **原问题**：`package.json` 与 `dsh-plugin.json` 均为 `0.2.0`，但 [`lib/index.js:33`](file:///D:/Agent工作区/DeepSeek%20Harness工作区/dsh-solidworks-plugin/lib/index.js#L33) 遗留硬编码 `const PLUGIN_VERSION = '0.1.0';`。
- **修复方案**：
  复用项目现有的 `package.json` 作为唯一真相源（Single Source of Truth），在 `lib/index.js` 模块加载时动态提取版本号：
  ```javascript
  let pluginVersion = '0.2.0';
  try {
    const pkg = JSON.parse(readFileSync(path.join(PLUGIN_ROOT, 'package.json'), 'utf8'));
    if (pkg?.version) pluginVersion = pkg.version;
  } catch {
    // fallback to release baseline
  }
  export const version = pluginVersion;
  const PLUGIN_VERSION = pluginVersion;
  ```
- **收益**：彻底消除了跨文件硬编码版本漂移风险；后续版本升级时仅需维护 `package.json`，宿主报告与 MCP 握手版本号将自动同步。

### 4.2 验收测试结果
- 在 `tests/mcp.test.js` 中新增断言：
  `✔ DEF-03: package.json, dsh-plugin.json, and lib/index.js report identical version (0.90ms)`
- 验证 `package.json.version === manifest.version === lib.version === '0.2.0'`，且 `libVersion !== '0.1.0'`。
