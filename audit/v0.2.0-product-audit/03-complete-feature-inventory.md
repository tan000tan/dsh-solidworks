# dsh-solidworks-plugin 全量功能清单与能力盘点 (Feature Inventory)

> **报告编号**：`03-complete-feature-inventory`  
> **基线版本**：v0.2.0 (Commit: `7d70bc0`)  
> **审计目标**：全量盘点软件内所有功能实体（包括 Meta 工具、CLI 子命令、运维脚本、MCP 底层工具与 CAD 模块），逐项刺穿调用链、API 真实性与测试覆盖。  

---

## 一、功能清单判定标准
- **代码位置**：具体文件与实现函数；
- **调用入口**：`CLI` / `DSH Host` / `MCP` / `Internal Script`；
- **SolidWorks API**：是否真实调用 COM 接口（如 `ISldWorks`, `IModelDoc2`, `IPartDoc`, `IFeature` 等）；
- **测试情况**：`Unit(Mock)` / `Regression` / `Live CAD(实机)` / `None`；
- **用户可用性**：普通用户是否开箱可用（考虑默认 `read-only` 策略及环境要求）。
